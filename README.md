# Dead Signal

Open `index.html` in your browser to play. No installation or build step is needed.

- WASD or arrow keys: move
- Mouse: aim; hold left click: fire
- Left Shift: sprint
- R: reload
- Escape: pause / resume

Survive increasingly difficult waves. Green supply boxes restore ammunition; orange medical boxes restore health. Clearing a wave gives 24 reserve rounds. Your best elimination count is saved in your browser when storage is available.

Designed for a desktop with keyboard and mouse. The game works offline; optional web fonts fall back to installed fonts.

## Publish with GitHub Pages

1. Create a public GitHub repository named `dead-signal`.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repository's `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish deploying. The playable game will be at `https://wrightiv-dotcom.github.io/dead-signal/`.

No build command or package installation is required.
